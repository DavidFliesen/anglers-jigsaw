Angler's Jigsaw v3.8.1 code-review repair

Code review findings fixed:
1. Image URLs were single-path hard coded. The loader now probes canonical short paths plus the previous nested asset paths and case variants.
2. v3.8.0 only packaged species 11-15. This repair includes available real assets for species 6-15 and can still locate species 1-5 at their previous nested locations.
3. Ambient fish used a fixed 55-second removal timer even when the CSS animation ended sooner. When animation ended, the element snapped back to left:0 and remained visible, causing the vertical stack. Fish now remove themselves on animationend, with a timeout only as a safety net.
4. Horizontal flipping previously assumed every source image faced right. The code now compares source facing against travel direction and flips only when required.
5. Larger ambient fish receive a higher depth z-index inside the background layer, while the entire ambient layer remains below app UI.
6. PWA cache/version bumped to v3.8.1 so Safari/GitHub Pages does not keep serving the faulty scripts.
7. Puzzle drag/layout mechanics were not rewritten.

Changed PWA files:
- index.html
- css/styles.css
- js/app.js
- js/data.js
- sw.js

Required image assets bundled:
- species 6-15 transparent/swimming and puzzle assets available in the current build workspace

Species 1-5:
- code probes both assets/fish + assets/puzzles and the previous assets/images/fish/transparent + assets/images/fish/puzzles locations, so the original first-batch artwork does not need to be renamed if it is still in the repository.
