Angler's Jigsaw v3.9.0 — clean rebuild review

SOURCE OF TRUTH
- Rebuild started from the exact GitHub ZIP supplied by the user.
- The v3.8.2 package contained a mixture of legacy filenames and the newer numbered naming convention.
- Several canonical image files were genuinely absent, which caused the visible "Artwork file is not installed" cards.

PRIMARY ROOT CAUSE
- The app data had moved to a numbered canonical convention such as:
    assets/fish/02_smallmouth_bass_large.png
    assets/puzzles/02_smallmouth_bass_puzzle.png
  while the repository still contained only some of those files and several older legacy names.

RECOVERY DECISIONS
1. Use one image naming convention only.
2. Package every required species asset with the PWA instead of relying on filename fallbacks.
3. Keep the known-good v3.5.7 puzzle/drag stability approach.
4. Do not add new species while recovering the broken 15-species build.
5. Keep visible collection naming as Fish Caught.
6. Preserve the old local-storage key internally so prior catches remain available.

PUZZLE ENGINE REVIEW
- Piece edge relationships are generated once and opposing edges match.
- Piece SVG shapes and board cutlines use the same edgeSegment/ribbonProfile geometry.
- Deep circular tabs/blanks are preserved.
- Correct placement snap-lock remains.
- Table pieces are not rebuilt on ordinary syncs; SVG is rebuilt only when geometry is dirty.
- Board relayout is blocked during active dragging.
- Safari URL-bar-only height changes are ignored.
- Genuine resize events are debounced.
- Play-table bounds are cached at drag start.
- Orientation changes during drag are deferred.
- Dragging a loose piece back onto the Tackle Tray returns it to the tray.
- Edges to Table scatters edge pieces.
- All to Table now scatters all unlocked pieces and does not silently turn into a different "Recall Singles" command.

ASSET REVIEW
- A duplicate Walleye/Sauger puzzle-art file was detected during final hash review; Sauger now has its own distinct puzzle image.
- 15 transparent fish assets are present under assets/fish/.
- 15 4:3 puzzle images are present under assets/puzzles/.
- The real home logo remains assets/images/logo.png.
- Icons remain assets/icons/icon-192.png and assets/icons/icon-512.png.
- Legacy species filenames and the redundant nested ambient folder are omitted from the replacement build.
- Coral reef and sunken pirate ship artwork are retained at `assets/themes/` instead of the deeper `assets/images/themes/` path.

AMBIENT FISH REVIEW
- Ambient layer is below app-shell/header/footer stacking contexts.
- Each fish chooses left or right travel randomly.
- Source-facing direction is compared with travel direction.
- scaleX(-1) is applied only when needed.
- Larger fish receive higher depth ordering within the ambient layer.
- Fish nodes are removed immediately at animation end so they cannot stack at the edge.
