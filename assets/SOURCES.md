# Fish Artwork and Reference Notes — v3.9.0

This recovery package uses a mixture of previously generated Angler's Jigsaw artwork and reconstructed recovery artwork.

The species records in `js/data.js` retain educational reference guidance pointing to authoritative fishery sources such as the U.S. Fish & Wildlife Service, NOAA Fisheries, and state fishery agencies.
