ANGLER'S JIGSAW v3.9.0 — QUICK FULL-SITE REPLACEMENT

IMPORTANT:
Extract the ZIP first. Do NOT upload the ZIP itself into the GitHub repository.
The files inside the extracted folder must become the repository root, with index.html at the top level.

FASTEST / MOST RELIABLE METHOD — GITHUB DESKTOP ON A MAC OR PC
1. Download and extract `anglers-jigsaw-v3.9.0-complete-site.zip`.
2. Open GitHub Desktop and clone/open `DavidFliesen/anglers-jigsaw`.
3. In Finder/File Explorer, open that local repository folder.
4. Delete the existing working files and folders in the repository. Do not delete the hidden `.git` folder if you are managing the repository manually.
5. Copy ALL CONTENTS of the extracted v3.9.0 folder into the repository root.
   The root should immediately contain:
      index.html
      manifest.json
      sw.js
      css/
      js/
      assets/
6. Return to GitHub Desktop. It should show the removed old files and the new/replacement files.
7. Commit with a message such as:
      Replace site with Angler's Jigsaw v3.9.0 clean rebuild
8. Click Push origin.
9. Allow GitHub Pages a minute or two to deploy.
10. On the iPad, fully reload the page. The v3.9.0 service worker uses a new cache name and deletes the prior app cache during activation.

BROWSER-ONLY ALTERNATIVE
1. Extract the ZIP locally.
2. Open the repository in GitHub's web editor (`github.dev`; pressing `.` while viewing the repo in a desktop browser opens it).
3. Remove the old site files/folders.
4. Add the extracted v3.9.0 contents at the repository root, preserving the folders.
5. Commit the changes to `main`.
6. Wait for GitHub Pages to redeploy and reload the site.

VERIFY AFTER UPLOAD
- Footer says v3.9.0.
- Home screen shows the actual Angler's Jigsaw logo.
- Choose a Fish shows all 15 species with artwork.
- A 48-piece puzzle shows traditional matching tabs/blanks on both the pieces and board cutlines.
- Edges to Table and All to Table work.
- A loose piece can be dragged back into the Tackle Tray.
- Ambient fish swim behind the interface and flip horizontally only when their direction requires it.
